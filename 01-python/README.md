# 01 — Python

Python is the FDE's everyday tool: scripting, gluing systems together, calling APIs, cleaning customer data and shipping small reliable services.

Work through the topics in order. Each folder has a `README.md` (overview), `notes.md` (detailed notes), `examples/` and `exercises/`.

| 03 | [Data Structures](03-data-structures/) | list, tuple, dict, set, collections |
| 04 | [Functions](04-functions/) | args, return, scope, lambdas, type hints |
| 05 | [Files & Errors](05-files-and-errors/) | reading/writing files, pathlib, exceptions |
| 06 | [Modules & Environments](06-modules-and-envs/) | imports, stdlib, pip, venv |
