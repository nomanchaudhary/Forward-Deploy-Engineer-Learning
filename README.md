## How each topic is organized

```
NN-topic/
├── README.md      # overview: what you'll learn
├── notes.md       # detailed notes with examples (add your own notes too)
├── examples/      # small runnable snippets
└── exercises/     # practice problems + my solutions
```

## Conventions

- One topic at a time; tick the items in [CHECKLIST.md](CHECKLIST.md) when done.
- Commit after every study session with a clear message, e.g. `python/01-basics: add loops exercises`.
- Run code with `python3 path/to/file.py`.
